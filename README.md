# PatrolIQ - Smart Safety Analytics Platform

A crime analytics project built for the GUVI Data Science capstone, using
unsupervised machine learning to identify crime hotspots and time-based crime
patterns in Chicago crime data.

## Problem Statement

Analyze Chicago crime records to help answer questions like:
- Where should police patrol tonight?
- Which neighborhoods need more resources?
- When do most crimes occur?

## Dataset

- **Source:** Chicago Data Portal - Crimes 2001 to Present (official public dataset)
- **Sample used:** 100,000 recent crime records (downloaded via the dataset's CSV
  export endpoint with a row limit, since the full 7.8 million row dataset is too
  large for a normal student laptop)
- **Original columns:** 22
- **After cleaning:** 99,939 rows (dropped 61 rows missing coordinates)

## How to Run the Notebooks

1. Install the required packages:
   ```
   pip install pandas numpy matplotlib seaborn scikit-learn mlflow scipy
   ```
2. Open the `notebooks/` folder in VS Code or Jupyter.
3. Run the notebooks **in order** (01 through 06), since later notebooks depend on
   output files saved by earlier ones.

## How to Run the Streamlit App Locally

```
cd app
pip install -r requirements.txt
streamlit run Home.py
```

## How to Deploy on Streamlit Cloud

1. Push this project to a GitHub repository.
2. Go to [share.streamlit.io](https://share.streamlit.io) and connect your GitHub account.
3. Select the repository, set the main file path to `app/Home.py`.
4. Deploy.

## How to View MLflow Experiment Tracking

```
mlflow ui --backend-store-uri sqlite:///mlflow.db
```
Then open the printed link (usually `http://localhost:5000`) in a browser.

## Techniques Used

| Step | Technique |
|---|---|
| Data Cleaning | Pandas (dropna, fillna) |
| Feature Engineering | Manual temporal feature extraction, custom severity score |
| Encoding | Label Encoding |
| Scaling | StandardScaler |
| Geographic Clustering | K-Means, DBSCAN, Hierarchical (Agglomerative) Clustering |
| Temporal Clustering | K-Means |
| Dimensionality Reduction | PCA, t-SNE |
| Experiment Tracking | MLflow |
| Deployment | Streamlit / Streamlit Cloud |

## Key Results

- **Best geographic clustering algorithm:** K-Means (silhouette score 0.40),
  chosen for deployment due to its clean, interpretable zones and ability to
  scale to all 100,000 rows.
- **DBSCAN:** Found 6 natural hotspot zones (eps=0.1, min_samples=20), with 86
  points marked as noise/outliers.
- **Hierarchical Clustering:** Run on a 5,000-row sample due to computational
  cost, silhouette score 0.37.
- **Temporal Clustering:** Found 4 distinct time-based crime patterns using
  K-Means on hour/day/month, including a clear late-night crime cluster.
- **PCA:** Needed 6 components to reach 71.4% variance explained (2-3 components
  alone only explained ~37-49%, since our features span several independent
  aspects of a crime - location, time, type, and status).
- **t-SNE:** Used on a 5,000-row sample for 2D visualization (full-dataset t-SNE
  is computationally impractical).

## Honest Notes on Results

Several "expected results" in the original project brief (like a silhouette score
above 0.5) were aspirational targets rather than guaranteed outcomes. Real-world
crime data is messy and doesn't separate into perfectly distinct clusters like a
textbook example. Throughout this project, we prioritized honest, explainable
results over forcing metrics to hit specific targets.
